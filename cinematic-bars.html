电影挡条

CINEMATIC BARS

按住左 Shift，上下两条黑边从画面外滑进来，把游戏压成电影画幅。松手，它们沿同一条曲线退回原处。

从 AstraLex 光影包里的「潜行挡条」抽出来的一件独立小模组：不需要光影包，不需要服务端，任何整合包里都能直接用。挡条高度、边缘羽化、过渡时长和缓动曲线都可以改。

参数

8.0%

单侧挡条占屏幕高度的百分比。模组默认 8%。

22%

挡条内侧的柔和程度，占挡条高度的百分比。0% 是硬边。

600 ms

一次完全展开或收起所需的时间。

九条曲线都来自模组的 Curve 枚举，下面那张表有对照。

两条边，一条曲线

  1. 01

    滑入

    上下两条挡条从画面外同时进入，左右对称，永远一起动。画面本身不裁切，FOV 也不动。

  2. 02

    外黑内透

    外缘是纯黑；向内 22% 的挡条高度里逐渐透明。所以挡条不会在画面上切出一道硬边，而是像画面自己暗下去。

  3. 03

    原路退回

    松手后沿同一条曲线反向滑出。曲线只决定加减速的形状，不改变挡条最后停在哪。

为什么不直接开光影

光影包里的潜行挡条只存在于那个 shader 里，换一套光影就没了。这个模组不依赖任何光影包：开不开光影、用哪个整合包，行为都一样。它是纯客户端的，服务端既不需要它，也察觉不到它。

全部写在一个 JSON 里

装了 YACL 和 Mod Menu 就能在游戏里调；没装的话直接改 config/cinebars.json，下次启动生效。

curve 的九个取值

每张小图都是把该曲线的 apply(t) 从 0 到 1 采样画出来的，和演示里用的是同一份函数。点一下，上面的放映室就换成这一条。

  1. 01 在启动器里装 Fabric Loader，版本按上面那张表。
  2. 02 把对应版本的 jar 放进 mods/，Fabric API 也放进去。
  3. 03 启动游戏，按住左 Shift。

想要游戏内调参数，再装 YACL 和 Mod Menu；不装也能用，改 config/cinebars.json 即可。不确定自己是哪个版本？看启动器里写的是「26.3」还是「1.21.10」，照这个数字选。
