Bliss 季节

BLISS SEASONS

树叶、草和天空跟着季节换色。三十秒一季，一轮两分钟。从夏天走进秋天的时候，树冠是慢慢烧红的，不会在某一帧突然跳过去。

这是从 Bliss Shaders 里抽出来的季节渲染。一棵树一年该有的颜色，现在不依赖光影包也能有：开着任何 Iris 光影包都能叠着用，关掉光影也照样生效。

权重、线性光、分帧

  1. 01

    先拆成四个权重

    一个周期是四段季节时长。每段末尾留出一小截过渡，长度就是「过渡时间」；过渡之外权重是干净的 1，也就是纯色，不掺下一季。上面时间轴上那几截金色就是曲线真正起作用的地方。

  2. 02

    在线性光里混

    季节色先转进线性光再按权重加权，最后转回 8 位 sRGB。直接在 sRGB 里平均，中间色会比两端都暗：冬天的白和秋天的红各占一半时，会混出一片发灰的粉。

  3. 03

    按距离分帧刷新

    48 格内每 2 tick 重刷一次，96 格内 4 tick，更远的地方 8 tick。自适应模式每 tick 最多推 96 个区块，改这个预算就是拿流畅度换显存带宽。

为什么不直接用光影自带的季节

Bliss Shaders 的季节写死在那个 shader 里，换一套光影就没了。这个模组把它抽成独立的客户端模组：任何 Iris 光影包都能叠着用，不开光影也照样换色。它只改客户端看到的颜色，不动群系、不动掉落、不动服务端，也不会让别人的屏幕变色。

一个 JSON，八个颜色

装了 Mod Menu 就能在游戏里调；没装就直接改 config/seasonalbliss.json，下次启动生效。EmLib 是配置库，jar 里已经带了，不用单独装。

关于 Java 25

这个 jar 编译到 Java 25 的字节码，Java 21 的运行时加载不了。电影挡条只要 Java 21，两者要求不同，别混着配。启动器里把 Java 路径指到 25 的 JDK 就行，游戏本身不用换。

  1. 01 在启动器里装 Fabric Loader 0.19.0 以上，Java 用 25。
  2. 02 把 jar 和 Fabric API 一起放进 mods/。EmLib 已经在这个 jar 里，不用再放。
  3. 03 启动游戏。季节会自己开始轮转，默认从夏天开始。

想调参数就再装 Mod Menu，EmLib 不用另装。想立刻看到原版颜色，把 colorIntensity 调成 0，或者关掉 enableSeasons。天气默认是关的，开了也只改你自己屏幕上的雨雪。
