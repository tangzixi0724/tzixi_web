规格

运行环境
电影挡条 Minecraft 26.3 与 1.21.10 两条构建；四季流转 26.3。都是 Fabric Loader，前者要 Java 21，后者要 Java 25。
依赖
两个都要 Fabric API。电影挡条可选 YACL 与 Mod Menu；四季流转可选 Mod Menu 与 Iris，它用的配置库已经打进 jar，不用另装。
最近更新
电影挡条 v1.0.0 · 2026-10-17 发布；四季流转 v1.1.1 已构建，还没上传到 Releases。同名模组的多条构建互相独立，下载前看清游戏版本。

关于

这里放我自己写的 Minecraft 模组，目前都是 Fabric 客户端向的小工具：不改服务端，不改存档，装错了删掉就行。

每个介绍页里都有一块能动手的模拟画面，不用开游戏就能看到效果：挡条能按着进出，季节能拖着时间轴换色。两处的几何与配色都按模组的实际算法算，不是录屏 —— 去放映室按一下，或者 拖一拖季节时间轴。

源码在 GitHub，问题反馈走 issues。每个模组页上都有可以直接下载的 jar，下载前先看清对应的游戏版本。
